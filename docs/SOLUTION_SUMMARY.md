# Описание решения — команда «вувузела без семена»

**Кейс:** двухэтапный мониторинг природных пожаров по данным ДЗЗ (VIIRS, Sentinel-2, Sentinel-1).
**Репозиторий:** https://gitverse.ru/hackrus.experts/kosmo-krasnoiarsk_vuvuzelabez_semena_37

## Что сделано

Комплекс из двух расчётных модулей, единый файл ответа в формате RLE, скрипт
метрики и информационно-аналитический сервис с REST API и картой.

**Модуль 1 — активное горение (VIIRS I1–I5, AF-чип 256×256 @ 375 м).**
Отбор кандидатов по мягким порогам I4 и I4−I5, контекстная статистика фона в
окне 21×21, отбраковка четырёх источников ложных срабатываний (техногенные
термоаномалии по типу покрова, солнечный блик по SWIR, вода по NDVI, край
облака/дым по разбросу фона). Финальное решение принимает градиентный бустинг
на 20 признаках, обученный на пиксельных кандидатах.

**Модуль 2 — гарь и степень поражения (Sentinel-2 до/после 512×512 @ 20 м +
Sentinel-1, рельеф, покров).** Индексы NBR/dNBR/RdNBR/dNDVI по обеим датам,
пороги dNBR, привязанные к типу земного покрова (откалиброваны по факту
размеченных гарей train-набора), маскирование облаков/теней по SCL и
восстановление контура под облаком по падению Sentinel-1 VH, морфологическая
чистка. Классы 0–3 предсказывает четырёхклассовый бустинг на спорных пикселях.

**Сервис.** REST API (`/api/query`, `/api/hotspots`, `/api/burn-scars`,
`/api/summary`) + веб-карта: термоточки за период, векторные контуры гарей с
выгрузкой в GeoJSON (EPSG:4326, атрибуты contour_id, severity_class, area_ha),
аналитическая справка по площади гари и распределению по степеням в CSV/JSON.

## Результаты

| Показатель | Значение |
|---|---|
| Score на train (self-eval, с моделью) | **0.71** |
| F1_af | 0.94 (precision 0.90, recall 0.98) |
| IoU_burn | 0.57 |
| mIoU_sev | 0.61 |
| Время инференса на тесте (269 чипов) | 50 с на 12 ядрах |
| Валидация submission.csv | пройдена (447 строк, формат корректен) |

Абляции на реальных данных показали, что итоговое решение сдаётся с обученной
моделью (Score 0.71 против 0.17 на чистых правилах): реальный фон достаточно
шумный, чтобы фиксированные пороги проигрывали бустингу, обученному на
кандидатах.

## Воспроизводимость

```bash
python -m pip install -r requirements.txt
python inference.py --data-dir /path/to/test --output submission.csv
```

Веса включены в репозиторий (`data/weights/`) и воспроизводимы командой
`python train.py --data-dir data/train --output-dir data/weights --calibrate-thresholds`
с фиксированным seed. Есть Dockerfile. Инференс детерминирован: повторный запуск
даёт побайтово тот же файл ответа. Полный отчёт — `docs/REPORT.md`,
план защиты — `docs/PRESENTATION.md`.

## Данные и лицензии

Внешние предобученные модели не применялись. Готовые продукты активного
горения и выгоревших площадей (FIRMS, VNP14, MCD64A1 и прочие) не
использовались. Библиотеки: NumPy, SciPy, pandas, scikit-learn, rasterio,
Shapely, FastAPI, Uvicorn, PyYAML (открытые лицензии BSD/MIT/Apache-2.0),
Leaflet + OpenStreetMap в веб-карте.
